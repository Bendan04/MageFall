# Description
MageFall is a mage fighting arena 3D game. This game will be one of my first real attempts at creating a world where players can interact with the enviroment and other enemies. This game is currently in very early development so any bugs and problems can be reported here for future implimentation.

# Initial Files
I created this using unity version 6000.5.7f1. All initial files created are the default files for creating a 3D rendered world within this version of unity with none of the extra additions.
